# Day 15 - Model Evaluation Metrics

## Objective
Learn how to evaluate a classification model using different
performance metrics.

## Dataset
Breast Cancer Wisconsin dataset from Scikit-learn.

- Samples: 569
- Features: 30
- Classes: Malignant and Benign

## Model
Logistic Regression

## Evaluation Metrics
- Accuracy: Overall proportion of correct predictions.
- Precision: How many positive predictions were correct.
- Recall: How many actual positive cases were identified.
- F1-score: Harmonic mean of precision and recall.
- Confusion Matrix: Shows correct and incorrect predictions.

## Libraries Used
- Scikit-learn
- Matplotlib
- Seaborn

## What I Learned
- How to evaluate a classification model.
- How to print a classification report.
- How to create and interpret a confusion matrix.
