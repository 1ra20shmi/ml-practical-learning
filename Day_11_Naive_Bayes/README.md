
# Day 11 - Naive Bayes Classification

## Objective
Learn how to build a classification model using Gaussian Naive Bayes.

## Dataset
Breast Cancer Wisconsin dataset from Scikit-learn.

- Total samples: 569
- Total features: 30
- Training samples: 455
- Testing samples: 114

## Concepts Learned
- Naive Bayes classification
- Probability-based prediction
- Training and testing data
- Accuracy, precision, recall, and F1-score
- Confusion matrix visualization

## Steps Performed
1. Loaded the dataset.
2. Split the data into training and testing sets.
3. Trained the Gaussian Naive Bayes model.
4. Predicted the test data.
5. Evaluated model performance.
6. Plotted the confusion matrix.

## Algorithm
Gaussian Naive Bayes assumes that each feature follows a Gaussian (normal) distribution within each class.
