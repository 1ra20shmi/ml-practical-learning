# Day 1 - ML Libraries

## Objective

Learn the basic Python libraries used in Machine Learning.

## Libraries Learned

### NumPy
Used for numerical calculations and arrays.

### Pandas
Used for loading, manipulating, and analyzing datasets.

### Matplotlib
Used for creating graphs and visualizations.

### Seaborn
Used for statistical data visualization.

### Scikit-learn
Used for Machine Learning algorithms, preprocessing, training, prediction, and evaluation.

## Practical Work

- Created NumPy arrays
- Calculated mean, maximum, minimum, and sum
- Created a Pandas DataFrame
- Explored DataFrame rows and shape
- Created a Matplotlib line graph
- Created a Seaborn scatter plot
- Trained a simple Linear Regression model
- Made a prediction using Scikit-learn

## ML Workflow Learned

Dataset → Preprocessing → Training → Prediction → Evaluation
