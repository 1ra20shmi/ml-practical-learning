
# Day 7: Decision Tree Classification

## Objective
To understand and implement a Decision Tree Classification model using Python and Scikit-learn.

## Dataset
Iris dataset containing flower measurements from three species:
- Setosa
- Versicolor
- Virginica

## Steps Performed
1. Loaded the Iris dataset.
2. Split the dataset into training and testing sets.
3. Created a Decision Tree Classifier.
4. Trained the model using training data.
5. Predicted flower species for test data.
6. Evaluated the model using accuracy, precision, recall, and F1-score.

## Results
- Training samples: 120
- Testing samples: 30
- Accuracy: 100%

## Libraries Used
- Python
- Scikit-learn

## Key Learning
Learned how a Decision Tree Classifier makes predictions using decision rules and how to evaluate a classification model.
