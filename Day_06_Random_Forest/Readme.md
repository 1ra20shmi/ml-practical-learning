
# Day 6 - Random Forest Regression

## Objective
Build a Random Forest Regression model to predict
house prices using the California Housing dataset.

## Concepts Learned
- Random Forest Regression
- Ensemble learning
- Training and testing data
- Model predictions
- MAE, RMSE, and R2 evaluation metrics

## Results
- MAE: 31628.41
- RMSE: 48941.70
- R2 Score: 0.8172

## Conclusion
Random Forest performed better than Linear Regression
and Decision Tree Regression on the recorded test results.
